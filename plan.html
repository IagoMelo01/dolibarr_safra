Data: 2026-05-21 Branch: main Commit inspecionado: 031312e PHP local: 8.2.26 Testes locais: passando

Resumo executivo

O modulo Safra ja possui uma base operacional relevante: CRUDs agronomicos, mapas, visao satelital, workflow de atividades agricolas, integracao com estoque, sincronizacao com tarefas de projeto, API REST e uma suite minima de testes. O modulo ainda nao deve ser tratado como pronto para producao sem um ciclo de hardening e homologacao.

  • Pronto para evoluir: Activity, API, schema canonico, testes basicos e runbook existem.
  • Bloqueios de producao: hardening SSL no Sentinel, rotacao de credenciais, definicao da estrategia de migracao destrutiva, homologacao em staging e limpeza documental.
  • Maior risco funcional: regra de reabertura/alteracao de atividades concluidas com movimentacao de estoque.
  • Maior risco operacional: ativacao em ambientes enxutos por causa da lista ampla de dependencias em core/modules/modSafra.class.php.
